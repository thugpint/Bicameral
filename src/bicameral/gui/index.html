Setup

Claude Code plans the work and reviews every change. A second model writes the code. Two steps to connect, one optional.

  1. 1

    Sign in to Claude Code

    The planner and reviewer. Uses your Claude account, no API key. The sign-in happens in Claude's own window, never on this page.

  2. 2

    Add a coder optional

    Codex is ChatGPT's coding tool. Install it and sign in with ChatGPT to use any model on your plan. Or add an Anthropic or OpenAI API key under Settings. Skip this and Claude does both jobs.

  3. 3

    Connect to Claude Code

    Adds the /bicameral command to Claude Code. One click.

Ready

Restart Claude Code, open a project, and type:

/bicameral fix the failing test

Claude asks which coder to use, plans the steps, and shows every diff before it is accepted.

Run a task

The same engine as /bicameral, run from this page with the models you pick. Nothing is committed; you review the changes afterwards.
